# Hello World

Welcome to **Shell Blog** — a terminal-style blog in your browser.

## Features

- Markdown rendering with full GFM support
- LaTeX math formulas via KaTeX
- Code syntax highlighting
- Embedded slideshows
- Shell commands: `ls`, `cat`, `wc`, `grep`, `sort`, and more

## Quick Start

```bash
help          # show available commands
ls            # list all posts
cat hello     # read this post
```

## About

This blog simulates a Unix terminal. Every blog post is a "file" you can read with `cat`, search with `grep`, and sort with `sort`.

> "The best interface is the one you already know."
